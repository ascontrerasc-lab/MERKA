MERKA UNIFICADO V10

Cambios principales:
- Admin vuelve a tener inicio de sesión directo desde /admin/.
- El acceso Admin valida Firebase Authentication y el permiso admin del documento users/{uid}.
- Delivery tiene una pantalla de ingreso/registro visualmente alineada con MERKA principal.
- Delivery conserva el flujo de código de entrega de 4 dígitos.
- Se mantienen los cambios V9: logo de tienda por archivo/URL, flujo de pedido y paneles.

IMPORTANTE:
- No existe registro público de administradores. Para una cuenta maestra, crea el usuario en Firebase Authentication y su documento users/{uid} debe tener isAdmin:true y roles:["admin"].
- Antes de producción, cerrar las reglas abiertas de Firestore.
