MERKA UNIFICADO V7 — correcciones

Cambios principales:
- Login: no entra automáticamente al abrir; requiere pulsar Iniciar sesión.
- Mensajes de acceso más claros para campos vacíos, credenciales incorrectas y otros errores.
- Live comprador: suscripción reforzada a video/audio de Agora, incluyendo transmisiones iniciadas antes de que el comprador entre.
- Admin: nueva sección Lives con botón Finalizar Live.
- Admin: reconoce role=admin, isAdmin=true o roles que contenga admin.
- Delivery: una cuenta admin también puede entrar para supervisar/probar el módulo.
- Comprador/Vendedor siguen unificados en la app principal.

IMPORTANTE:
- El token de Agora incluido sigue siendo TEMPORAL. Cuando expire, el Live necesitará un token nuevo o, como solución definitiva, un servidor de tokens.
- Las reglas abiertas de Firestore son solo para desarrollo. Deben asegurarse antes de uso público.
