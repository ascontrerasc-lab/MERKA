MERKA UNIFICADO V5 — MVP DE PRUEBA

ESTRUCTURA
- /index.html = MERKA principal: una cuenta, Modo Comprar + Modo Vender.
- /admin = panel Admin separado.
- /delivery = panel Delivery separado.
- /comprador y /vendedor redirigen a la app principal para conservar enlaces antiguos.

INCLUYE
- Registro/login único Firebase.
- Activar tienda con la misma cuenta y cambiar Comprar ↔ Vender sin cerrar sesión.
- Crear, activar/desactivar y eliminar productos.
- Eliminar tienda conservando la cuenta de comprador.
- Imagen por URL o cámara/archivo (comprimida para el MVP).
- Perfil de tienda + sus productos.
- Chat comprador-vendedor en Firestore.
- Comentarios de productos + respuesta del vendedor.
- Carrito y creación de pedidos.
- Pedidos comprador/vendedor.
- Live Agora host/audience + comentarios Firebase + producto destacado.

IMPORTANTE
1. El token Agora incluido es TEMPORAL y expirará. Si expira, solo el Live fallará.
2. Las reglas Firestore abiertas son solo para desarrollo. Antes de publicar MERKA hay que asegurar Auth/Rules.
3. Las fotos cámara/archivo se guardan como data URL comprimida en Firestore SOLO para prototipo. Para producción debe usarse Firebase Storage/Cloud Storage.
4. Pago sigue siendo simulado; Mercado Pago no está integrado.
